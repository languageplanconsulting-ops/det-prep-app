# ⚠️ The Thai Trap List
### 60 errors your students are already making — and the fix for each

**Why this file exists.** Boonraksa & Naisena (2022) and Yumanee both found that **L1 transfer is the number-one source of collocation error in Thai EFL students**, with preposition patterns producing the highest error counts and adjective+noun the worst lexical pattern (21.31% of violations).

**The pedagogical principle:** Thai students have already automated these wrong forms. You cannot overwrite an automated error by showing only the correct version — the student reads the correct form, nods, and then produces the wrong one under time pressure. **You must show the error and the fix side by side, once, explicitly.** Then never show the error again.

**Layout rule for the book:** wrong form struck through in grey, correct form in bold black, Thai reason in a small blue line. Never put the wrong form on a flashcard.

## Group 1 — ⚠️ T-PREP: the missing preposition (20)

**Root cause:** the Thai verb carries its object directly (ฟังเพลง = listen-music). English requires a preposition that has no Thai equivalent, so it disappears.

| ❌ | ✅ | ไทย | คำอธิบาย |
|---|---|---|---|
| ~~listen music~~ | **listen to** music | ฟังเพลง | ไทยไม่มีคำเชื่อม อังกฤษต้องมี **to** เสมอ |
| ~~wait me~~ | **wait for** me | รอฉัน | ต้องมี **for** |
| ~~depend the weather~~ | It **depends on** the weather | ขึ้นอยู่กับอากาศ | "กับ" = **on** |
| ~~discuss about~~ | **discuss** the problem | คุยเรื่องปัญหา | ตรงข้าม! discuss **ไม่มี** about |
| ~~explain me~~ | **explain to** me | อธิบายให้ฉันฟัง | ต้องมี **to** |
| ~~answer to my question~~ | **answer** my question | ตอบคำถาม | verb ไม่มี to (แต่ noun *the answer **to*** มี) |
| ~~marry with~~ | **married to** | แต่งงานกับ | "กับ" ≠ with ตรงนี้ |
| ~~arrive to Bangkok~~ | **arrive in** Bangkok | มาถึงกรุงเทพ | เมือง/ประเทศ = **in**, สถานที่ย่อย = **at** |
| ~~good in English~~ | **good at** English | เก่งภาษาอังกฤษ | ทักษะ = **at** |
| ~~interested about~~ | **interested in** | สนใจ | |
| ~~different with~~ | **different from** | ต่างจาก | US ใช้ *from*; *than* ก็พบใน US |
| ~~similar with~~ | **similar to** | คล้ายกับ | |
| ~~worried for~~ | **worried about** | เป็นห่วง | |
| ~~afraid to spiders~~ | **afraid of** spiders | กลัวแมงมุม | + noun ใช้ **of** |
| ~~pay the ticket~~ | **pay for** the ticket | จ่ายค่าตั๋ว | จ่าย*ค่า*บางอย่าง = **for** |
| ~~ask help~~ | **ask for** help | ขอความช่วยเหลือ | |
| ~~search my keys~~ | **search for** / **look for** my keys | หากุญแจ | |
| ~~concentrate in~~ | **concentrate on** | ตั้งสมาธิกับ | |
| ~~reason of~~ | the **reason for** | เหตุผลของ | |
| ~~solution of~~ | the **solution to** | ทางแก้ของ | |

## Group 2 — 🔁 T-LIT: word-for-word from Thai (15)

| ❌ | ✅ | ไทย ที่เป็นต้นเหตุ |
|---|---|---|

## Group 3 — 🔀 T-VERB: ทำ = do / make / take / have (13)

**Root cause:** one Thai verb **ทำ** maps onto four English verbs. Students default to *do*.

| ❌ | ✅ | ไทย |
|---|---|---|
| ~~do a mistake~~ | **make** a mistake | ทำผิด |
| ~~do a decision~~ | **make** a decision | ตัดสินใจ |
| ~~do a party~~ | **have / throw** a party | จัดปาร์ตี้ |
| ~~make homework~~ | **do** homework | ทำการบ้าน |
| ~~make an exam~~ | **take** an exam | สอบ |
| ~~do a photo~~ | **take** a photo | ถ่ายรูป |
| ~~make a shower~~ | **take** a shower | อาบน้ำ |
| ~~do an appointment~~ | **make** an appointment | นัดหมาย |
| ~~make exercise~~ | **do / get** exercise · **work out** | ออกกำลังกาย |
| ~~do a plan~~ | **make** a plan | วางแผน |
| ~~make a break~~ | **take** a break | พัก |
| ~~do fun~~ | **have** fun | สนุก |
| ~~do a effort~~ | **make** an effort | พยายาม |

**Teaching device that works:** the four-column grid. Give students 40 nouns and have them sort into MAKE / DO / TAKE / HAVE. Sorting beats memorizing because it forces the contrast.

## Group 4 — 🎯 T-ADJ: the wrong adjective partner (12)

**Root cause:** Thai **หนัก / แรง / ใหญ่ / มาก** each map onto several English adjectives that are not interchangeable.

| ❌ | ✅ | ไทย |
|---|---|---|
| ~~strong rain~~ / ~~big rain~~ | **heavy** rain | ฝนตกหนัก |
| ~~heavy wind~~ | **strong** wind | ลมแรง |
| ~~much traffic~~ | **heavy** traffic | รถติดหนัก |
| ~~thick coffee~~ | **strong** coffee | กาแฟเข้ม |
| ~~near friend~~ | **close** friend | เพื่อนสนิท |
| ~~expensive price~~ | **high** price *(or just "expensive")* | ราคาแพง |
| ~~cheap price~~ | **low** price *(or just "cheap")* | ราคาถูก |
| ~~big noise~~ | **loud** noise | เสียงดัง |
| ~~much difference~~ | a **big** difference | ต่างกันมาก |
| ~~strong rain fall~~ | it's **raining hard / pouring** | ฝนตกหนักมาก |
| ~~very delicious~~ | **really / absolutely** delicious | อร่อยมาก |
| ~~very perfect~~ | **absolutely** perfect | สมบูรณ์แบบมาก |

## How to drill the trap list

| Stage | Activity | Why |
|---|---|---|
| 1. Confront | Show ❌/✅ pair once, with the Thai reason | The error must be made conscious to be overwritten |
| 2. Discriminate | Two-option forced choice under a 5-second timer | Speed pressure is where the old form resurfaces |
| 3. Produce | Gap fill with **no options given** | Recognition ≠ production |
| 4. Recycle | Same item reappears 3 units later, mixed with others | Spaced review measured **3× retention** vs massed |
| 5. Transfer | Free speaking / writing task that naturally requires it | Only this proves real learning |

**Never do:** a page of 20 sentences where the student "finds the mistake." That teaches error-spotting, not correct production, and it exposes the student to 20 more repetitions of the wrong form.
