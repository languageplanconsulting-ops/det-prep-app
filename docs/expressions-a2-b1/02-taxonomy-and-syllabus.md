# The categorization logic
### How to organize 600 multi-word items so a Thai A2→B1 student can actually learn them

---

## The core problem with existing books

Most Thai-market expression books use **one** organizing axis, and it is always the wrong one:

| Common approach | Why it fails |
|---|---|
| Alphabetical (A–Z phrasal verbs) | No memory hooks, no priority. Student learns `abide by` before `pick up`. |
| By particle only (all the `up` verbs together) | 40 unrelated meanings on one page. Interference — students confuse `give up` / `grow up` / `make up`. |
| By verb only (all the `get` verbs) | Same problem, reversed. |
| By topic only (Travel, Food, Work) | Frequency is ignored. A rare travel idiom gets the same weight as `find out`. |

**The fix: five independent tags per item, and use different tags for different jobs.** One axis decides chapter order, a different axis decides what goes in the chapter, a third decides how hard you drill it.

---

## The five-tag model

Every one of the 600 items in this book carries five tags.

```
find out  ·  หาคำตอบ / สืบให้รู้
├── FORM   : PV                    → which practice exercise type
├── TIER   : 1  (Core 100)         → productive vs receptive; how many drills
├── THEME  : U04 School & Study    → which chapter it lives in
├── TRAP   : —                     → Thai-interference warning needed?
└── REG    : NEU · US=UK           → spoken/written; American-specific?
```

---

### Tag 1 — FORM (what kind of chunk is it?)

This decides **which exercise type** teaches it. Different forms need genuinely different practice.

| Code | Form | Example | The exercise that works |
|---|---|---|---|
| **PV** | Phrasal verb | *find out, pick up, turn in* | Particle-choice gap fill + separability drill |
| **COL-VN** | Verb + noun | *make a decision, take a break* | Verb-choice grid (make/do/take/have) |
| **COL-AN** | Adjective + noun | *heavy traffic, close friend* | Odd-one-out; "which adjective goes with…" |
| **COL-AA** | Adverb + adjective | *absolutely amazing, pretty good* | Intensity ladder (a bit → pretty → really → totally) |
| **COL-P** | Word + preposition | *depend on, good at, reason for* | **Preposition gap fill — the #1 Thai error type** |
| **FUNC** | Functional chunk | *I'd rather…, How about we…* | Roleplay / dialogue substitution |
| **IDM** | Idiom | *a piece of cake, no big deal* | Meaning-match; context guessing |

**Why this matters:** a Thai student who can do `make a decision` in a verb grid still writes `*depend the weather`, because grammatical collocations (COL-P) are a different skill from lexical ones (COL-VN). Splitting FORM forces you to build both exercise types.

---

### Tag 2 — TIER (how hard do we drill it?)

Frequency-based, derived from the corpus evidence in the research brief. **This decides productive vs receptive**, which is the most important pedagogical decision in the book.

| Tier | Size | Status | Requirement | Drill load |
|---|---|---|---|---|
| **Tier 1 — Core** | 200 | **Productive** | Student must *produce* it in speaking and writing | 4+ encounters, 2 production tasks each |
| **Tier 2 — Active** | 250 | **Productive (written)** | Student must produce it in writing; recognize in speech | 3 encounters, 1 production task |
| **Tier 3 — Recognition** | 150 | **Receptive only** | Student only needs to *understand* it | 1 encounter, glossed in margin |

**The rule that saves your book:** never test Tier 3 productively. Thai students burn enormous effort trying to actively produce low-frequency items and then fail to produce `find out` fluently. Print the tier on the page so students know what to memorize and what to just meet.

**The sequencing rule:** *theme decides the chapter, tier decides who gets in.* Inside every unit, Tier 1 items come first and get the most practice. This gives you a book that feels topical to the student but is frequency-driven underneath.

### Tag 4 — TRAP (the Thai-interference flag)

**This is your book's competitive advantage.** The research is unambiguous that L1 transfer is the leading cause of Thai collocation error. Four trap subtypes, each with its own icon and its own fix:

| Code | Trap type | Thai cause | Example error → fix |
|---|---|---|---|
| **T-PREP** ⚠️ | Missing / wrong preposition | Thai verb takes no preposition | ❌ *I listen music* → ✅ **listen to** music |
| **T-LIT** 🔁 | Literal translation | Word-for-word from Thai | ❌ *play internet* (เล่นเน็ต) → ✅ **go online** |
| **T-VERB** 🔀 | Wrong delexical verb | Thai **ทำ** = do / make / take / have | ❌ *do a mistake* → ✅ **make a mistake** |
| **T-ADJ** 🎯 | Wrong adjective partner | Thai **หนัก/แรง** map to several English adj. | ❌ *strong rain* → ✅ **heavy rain** |

**How to print it:** show the wrong form struck through, in the same box, in red. Do not hide the error — Thai students have already internalized it, and the only way to overwrite it is to confront it explicitly.

```
┌─────────────────────────────────────────┐
│ ⚠️ T-PREP                                │
│  ❌ It depends the weather.              │
│  ✅ It depends ON the weather.           │
│     มันขึ้นอยู่กับสภาพอากาศ                  │
│  💡 ภาษาไทย "ขึ้นอยู่กับ" มี "กับ" อยู่แล้ว     │
│     ภาษาอังกฤษก็ต้องมี on เสมอ            │
└─────────────────────────────────────────┘
```

### Tag 5 — REG (register + American English)

Two sub-flags on one tag.

**Register** — decides whether the item goes in a dialogue or an essay:
- `SPK` — spoken only (*no big deal, my bad, hang out*) → dialogues, listening
- `NEU` — both (*find out, make a decision*) → anywhere
- `WRI` — written/formal-leaning (*carry out, point out, as a result*) → reading & writing tasks

**Variety** — decides whether it needs a British sidebar:
- `US` — American form that differs from British → **teach this, add grey sidebar**
- `US=UK` — same in both → no sidebar, no comment
- `UK` — British form → **Tier 3 recognition only, never taught productively**

**Recommendation:** do not build British-vs-American units. Make American the invisible default and put British forms in a small grey box titled *ถ้าไปเจอแบบอังกฤษ…* ("if you meet the British version…"). Students need to *recognize* British forms for listening tests but should *produce* only American ones.

## Putting it together: what a unit looks like

**Unit 13 — Plans, Decisions & Problems** (42 items)

| Section | Content | Tags pulled |
|---|---|---|
| 1. Warm-up dialogue | 8 items in context | any FORM, TIER 1 |
| 2. Phrasal verb focus | 10 PVs, **2 senses each** | FORM=PV, TIER 1–2 |
| 3. Verb grid | make/do/take/have + decision, plan, effort… | FORM=COL-VN, TRAP=T-VERB |
| 4. ⚠️ Thai trap page | 6 preposition traps | TRAP=T-PREP |
| 5. Speaking chunks | 8 functional frames | FORM=FUNC, REG=SPK |
| 6. Recycling box | 10 items **from units 1–12** | any, TIER 1 |
| 7. Recognition list | 6 items, glossed only | TIER 3 |

Section 6 is non-negotiable. Spaced review produced **three times** the retention of massed review in the studies cited in the brief — a recycling box in every unit is the cheapest way to buy that.

## Quick reference: the tag string

Every entry in files `03`–`05` is tagged like this:

```
turn in | ส่ง (การบ้าน/งาน) | PV | T1 | U04 | — | NEU · US (UK: hand in)
```

`item | Thai | FORM | TIER | THEME | TRAP | REG · VARIETY`

This string is machine-readable, so `master-list.csv` can be filtered to build any worksheet: *"all Tier-1 preposition traps in units 1–8"* is one filter away.
