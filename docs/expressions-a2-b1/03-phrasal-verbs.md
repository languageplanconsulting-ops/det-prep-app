# Phrasal Verbs — A2 to B1 (American English)
### 170 items · Tier 1 (60) productive · Tier 2 (60) productive-written · Tier 3 (50) recognition only

**How to use this file.** Tier 1 and Tier 2 carry example sentences because students must *produce* them. Tier 3 carries a Thai gloss only, because students only need to *recognize* them — do not build production exercises from Tier 3.

**Two senses maximum.** Where a phrasal verb has more than one high-frequency sense, both are listed and separated by `;`. Garnier & Schmitt found that for most phrasal verbs two senses cover 75%+ of real use — resist adding a third.

**Legend.** `🇺🇸` = American form differs from British (British given in Notes) · `SPK` = spoken/informal · `WRI` = written-leaning · `⚠️` = Thai interference trap

## Appendix A — The 8 particles that carry half of all phrasal verbs

Gardner & Davies found that **20 lexical verbs combined with just 8 particles account for 50.4%** of all phrasal verbs. Teach the particle's core spatial meaning once, in Unit 1, and every later item becomes cheaper to learn.

| Particle | Core idea | Thai hook | Examples from this list |
|---|---|---|---|
| **up** | completion / increase / upward | เสร็จสิ้น · เพิ่มขึ้น · ขึ้นข้างบน | fill up, clean up, use up, grow up, turn up |
| **out** | outward / removal / discovery | ออกไป · เอาออก · ค้นพบ | find out, take out, figure out, run out, point out |
| **on** | continuing / contact | ต่อเนื่อง · แตะติด | go on, keep on, put on, hold on, carry on |
| **off** | separation / stopping | แยกออก · หยุด | turn off, take off, set off, cut off, call off |
| **down** | downward / reducing / recording | ลง · ลดลง · บันทึก | write down, calm down, cut down, break down |
| **in** | entering / inside | เข้าไป · ข้างใน | get in, check in, hand in, fill in, move in |
| **back** | returning | กลับ | come back, give back, call back, pay back |
| **over** | across / reviewing / transferring | ข้าม · ทบทวน · โอนย้าย | go over, come over, take over, get over |

**Teaching tip for Thai students:** the particle is the meaning-carrier, not the verb. `up` in *clean up / eat up / finish up* always adds "จนเสร็จสมบูรณ์". Teaching this once replaces 30 separate memorizations.

## Appendix B — Separability (the rule Thai students break most)

| Type | Rule | Example |
|---|---|---|
| **Separable** | Noun object: either position. **Pronoun object: MUST split.** | *Turn off the light.* / *Turn the light off.* / ✅ *Turn it off.* ❌ *Turn off it.* |
| **Inseparable** | Never split | ✅ *Look after him.* ❌ *Look him after.* |
| **Three-word** | Never split | ✅ *Put up with it.* ❌ *Put it up with.* |

**The one-sentence rule to print in the book:**
> ถ้ากรรมเป็นสรรพนาม (**it, him, them, me, us**) และกริยาวลีนั้นแยกได้ — **ต้องแยกเสมอ**

This single rule fixes the most common Thai phrasal-verb error in writing.
