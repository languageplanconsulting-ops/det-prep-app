# Expressions & Fixed Chunks — A2 to B1 (American English)
### 169 items · organized by communicative FUNCTION, not by form

**Why function, not alphabet.** A student never thinks *"I need an idiom starting with H."* They think *"I need to disagree politely."* Functional grouping is the only organization that survives contact with real speaking practice — and it maps directly onto DET / IELTS / TOEFL speaking tasks.

**Legend.** `SPK` = spoken/informal · `NEU` = both · `WRI` = written-leaning · 🇺🇸 = American-specific · `T1/T2/T3` = tier

## Appendix — 20 spoken chunks that instantly sound American

For a pronunciation/fluency unit. These are **not** slang — they are the reduced forms of ordinary speech, and Thai students who never meet them fail listening sections.

| Written | Spoken (American) | ไทย |
|---|---|---|
| going to | **gonna** | จะ |
| want to | **wanna** | อยากจะ |
| got to / have got to | **gotta** | ต้อง |
| kind of | **kinda** | ประมาณว่า |
| sort of | **sorta** | ค่อนข้างจะ |
| a lot of | **a lotta** | เยอะ |
| let me | **lemme** | ขอ… หน่อย |
| give me | **gimme** | เอามาให้หน่อย |
| don't know | **dunno** | ไม่รู้ |
| what are you | **whatcha** | คุณกำลัง…อะไร |
| did you | **didja** | คุณ…หรือเปล่า |
| could have | **coulda** | น่าจะ…ได้ |
| should have | **shoulda** | น่าจะ… |
| would have | **woulda** | คงจะ… |
| out of | **outta** | ออกจาก |
| because | **'cause / cuz** | เพราะว่า |
| them | **'em** | พวกเขา |
| I have got a | **I gotta** | ฉันมี… |
| you all | **y'all** (Southern US) | พวกคุณ |
| I've gotten better | **gotten** (🇺🇸 only) | ฉันดีขึ้นแล้ว |

**Teaching note:** teach these for **listening comprehension and recognition**. Have students produce *gonna / wanna / gotta / kinda* (fully standard in American speech) but not the rest — a B1 student who writes *coulda* in an essay has been badly served.
